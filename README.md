# CodeAlpha_RandomQuoteGenerator

Task 2 – Random Quote Generator (CodeAlpha App Development Internship)

A clean, minimal quote app built with HTML, CSS and JavaScript (no libraries).

## Features
- Shows a random quote as soon as the app opens
- **New Quote** button shows a different quote on every click (never repeats the previous one)
- Each quote displays the text and the author's name clearly
- **Copy** button to copy the quote
- Responsive layout with automatic light/dark mode

## Run
Open `index.html` in any browser. No installation needed.

## Host free on GitHub Pages
Repo → Settings → Pages → Branch: `main` / root → Save.
